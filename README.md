# 🍳 献立食材リスト

料理を選ぶだけで、必要な食材と分量をまとめて買い物リストを作れるWebアプリです。

## できること

- **200品の定番料理から選ぶ**: 定番の家庭料理（ご飯・丼、麺類、肉料理、魚料理など）をタップして選べます。
- **人数に合わせた自動計算**: 1人〜4人分を切り替えると、食材の分量が自動で再計算されます。
- **食材の自動まとめ**: 複数の料理で同じ食材がある場合、分量を自動で合算します（※同一の単位で合算できる食材に限ります）。
- **買い物リストのコピー**: ワンタップでクリップボードにコピーして、メモアプリやLINEに貼り付けられます。
- **ブラウザ完結の安心設計**: 入力した内容やお使いのデータは、外部のサーバーには送信されず、お使いの端末（ブラウザ）内でのみ保存されます。

## 使い方

1. 画面上の「人数」ボタン（「1人」「2人」「3人」「4人」）から、作りたい人数を選びます。
2. 「料理を選ぶ」の一覧から、作りたい料理カードをクリック（タップ）して選びます（複数選択できます）。料理名や食材名で検索することもできます。
3. 画面右側（スマートフォンの場合は画面下部）の「🛒 買い物リスト」に、必要な食材と分量がまとまって表示されます。
4. 家にある調味料を除きたい場合は、「調味料を隠す」スイッチをオンにします。
5. 「📋 リストをコピー」ボタンを押すと、買い物リストがクリップボードにコピーされます。

## 制限・注意点

- 食材の合算は、同一の食材名かつ同一の単位（gや個など）の場合に行われます。単位が異なる場合（例:「1本」と「100g」）や、「少々」「適量」などの数値でないものは、無理に合算せず別々の行として表示されます。
- 選択状態はブラウザ（LocalStorage）に自動保存されます。ブラウザの履歴やCookieを削除すると初期状態に戻ります。
- クリップボードが使えない環境では、コピー時に買い物リストの全文が入力欄に表示されます。テキストを選択して手動でコピーしてください。

## 開発者向け情報

### 動作環境
- モダンブラウザ（Chrome, Edge, Safari, Firefox）
- 外部ライブラリへの依存なし（Vanilla HTML5 / CSS3 / JavaScript）

### ファイル構成
- `index.html`: アプリケーション画面
- `css/`: スタイルシート（変数、レイアウト、コンポーネント）
- `js/`: アプリケーションロジック（計算、状態管理、描画、イベント制御）
- `js/data.js`: 200品の料理データ（`scripts/data/` から自動生成。実行時に読み込むのはこのファイルです）
- `data/recipes.json`: 上記と同内容のJSON生成物（配布・参照用。実行時には読み込みません）

### テスト実行方法（開発リポジトリ）
テストは公開リポジトリには含まれていません。開発リポジトリ（`menu-ingredient-list-dev`）で実行します。
```powershell
node tests/calc.test.js
node tests/data.test.js
node tests/state.test.js
node tests/integration.test.js
```

## 外部通信

外部への通信は行いません（ブラウザ上のみで動作します）。

## 免責事項

本ツールは一般的な家庭料理のレシピ情報を基に食材を計算する支援ツールです。計算結果の正確さや網羅性について保証はしません。実際の購入・調理にあたってはご自身の判断でご確認ください。
